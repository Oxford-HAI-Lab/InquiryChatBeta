# DEADDOGMA: Do beliefs become empty dogma if never challenged?

## Parent context

The parent node gives four grounds for absolute liberty of discussion. This node is the third and fourth: even a true opinion, "if it is not fully, frequently, and fearlessly discussed, ... will be held as a dead dogma, not a living truth" (Ch. 2, para. 21).
